# Aerial：给国产电视换一块没有广告的桌面
*GitHub 开源观察 · 第 01 期 · 单篇 ①/4*

> 电视开机先看 15 秒广告，首页一半是会员推荐 —— 这不是电视的问题，是「桌面」被换掉了。Aerial 把桌面换回来。

你在电视上看到的那个「首页」，其实是厂商预装的一个 App，术语叫 launcher。开机广告、推荐位、会员角标、限时免费，全部是这个 App 长出来的，不是屏幕长出来的。所以理论上，换掉它就行了。

Aerial 就是干这件事的：一个照着 Apple TV 界面做的 Android TV 桌面。常用 App 放在屏幕下方的玻璃底板上，往下滚是全部 App（包括小米「应用中心」「米家」这种被藏起来的系统应用）。长按 OK 键可以移动、建文件夹、隐藏、卸载，还能把某个 App 或某个 HDMI 信号源设成「开机时打开」。

有几个功能不太常见：扫电视上的二维码，手机上会出一模一样的图标网格，可以在手机上拖动排序、改名、换图标；控制中心在第一排按上键打开，有信号源、网络、设置、音量、亮度；屏保用的是 Apple TV 那 114 段航拍影片，支持 4K 和杜比视界；壁纸可以是必应每日精选，也可以是手机扫码传的照片。

工程上最要紧的一点：不用 root，不动系统应用，随时能还原。这是它敢让普通人装的唯一理由 —— 一个要刷机的方案，写得再好也不会有人试。项目是 Kotlin 写的，MIT 协议，10 月 20 日建库，两周多到 1.1 万 star。

## 它替你省掉哪件烦事

烦的从来不是「没有好桌面」。烦的是每次开机要按三次遥控器跳过广告，然后在一屏推荐里找自己装的那几个 App；烦的是待机回来，焦点又被挪到厂商的推荐位上了。

这个东西不给你增加任何功能。它是减法的：把广告位、推荐流、会员角标从首页拿掉，把「你装了什么」还给你。所以别指望它让电视变快 —— 它只是让电视安静下来。

## 装之前，先确认三件事

- **系统**：Android TV 5.0 及以上；4.0–4.4 有单独的 Lite 测试版
- **品牌**：小米/Redmi、TCL/雷鸟、创维、海信/Vidda、OPPO、索尼都能装，盒子和投影仪也行
- **前置**：电脑和电视连同一个 Wi-Fi；电视要打开 ADB 调试（每个品牌的入口都不一样，这是整件事最烦的一步）
- **风险**：海信/Vidda 要进工厂菜单把 To Fac 从 U 改成 M。作者在文档里明确写了：反复改可能让 USB 失灵、要重置电视，只改一次

## 怎么装：让 AI 替你跑这一步

装这个东西，难的从来不是命令。难的是「我的电视是哪个品牌、ADB 开关藏在第几层菜单、我这台到底是 USB 调试还是只有无线调试」—— 这三件事每个品牌都不一样，README 里那张表有六个分支，普通人读到第三个就晕了。

而这正好是 AI 擅长、人不擅长的事：读长文档、按你的具体情况分流、一步一步等你操作。所以 Aerial 的作者直接把「让 Agent 装」写成了推荐路径，还专门写了一份给 Agent 看的安装说明（agent.md）。

有一件事必须说清楚：手机上的豆包、网页版聊天，只会把步骤告诉你，不会在你电脑上执行。要让它真的动手，得用能操作电脑的桌面版 —— WorkBuddy、豆包电脑版、千问电脑版、Trae 这类。差别不是聪明程度，是有没有手。

```text
请帮我把开源电视桌面 Aerial 装到我的电视上，并设为开机进入的桌面。

电视 IP：<把电视上的 IP 填这里>
保持 ADB 常开：要

安装说明在这里：https://aerial.qust.me/agent.md
（打不开就用 https://raw.githubusercontent.com/pengchujin/aerial-tv/main/site/agent.md）

要求：
1. 先完整读完安装说明再动手，不要凭印象给命令；我的电视型号和文档对不上时，先告诉我哪里对不上。
2. 一次只做一步：每步先说这一步干什么、有没有风险，等我回「继续」再执行下一条。
3. 命令你在我的电脑上自己执行，不要只把步骤贴给我。需要我在电视上点遥控器时，明确告诉我点哪里。
4. 报错就把原始输出贴给我看，先解释原因再修；不要连着换三种方案试。
5. 不要动电视的系统设置，不要改我已经装好的东西。

最后按安装说明里的「验收」，把这三条命令的原始输出原样贴给我（不要总结）：
- adb shell "cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME"
- adb shell settings get secure enabled_accessibility_services
- 按主页键后跑 adb shell "dumpsys window | grep mCurrentFocus"
```

它说装好了，别急着信 —— 看它贴出来的 mCurrentFocus 里有没有 app.orchard.tv。这是这个 App 的包名，在就说明桌面真的换过去了；不在就是没成，让它继续查。

卡在「找不到 ADB 开关」：把电视品牌、型号、系统版本一起丢给它，让它按型号给具体路径。通用步骤在这里没用，小米和 TCL 的入口差着三个菜单层级。

**用之前先知道**

- 电视 IP 在 设置 → 网络 → 已连接的网络 里，先自己找到再填进提示词
- 只让它在你电脑上装，别让它去动电视的系统设置 —— 工厂菜单那种地方，按错的代价是重置电视
- 装完如果你还想用 ADB 做别的，让它在安装时保留 ADB 常开；否则电视重启后端口就关了

## 不想用 AI？这两条命令也能装

```bash
# macOS / Linux 一行装（TV 换成你电视的 IP）
curl -fsSL https://aerial.qust.me/install.sh | KEEP_ADB=1 TV=192.168.1.20 bash

# 只有「无线调试」、没有 ADB 开关的电视，先配对
adb pair 192.168.1.20:37115     # 电视配对码屏幕上的端口
adb connect 192.168.1.20:39201  # 无线调试主页上的另一组端口

# 手动装：下载 APK 后
adb install -r aerial-standard.apk
```

Windows 上手动装要先装 platform-tools（adb）。索尼 BRAVIA Android 14 这类只有无线调试的电视必须先 adb pair；TCL Q10M、Q10L、鹤 6 Ultra 这些没有配对码入口的固件，得先用数据线连一次电脑授权。文档里还有一份分品牌的详细说明（docs/devices/adb-by-brand.md）。

## 第一次打开，先做这三件事

1. 按一下主页键，看是不是回到 Aerial 而不是厂商桌面 —— 这是最直接的验收
2. 进设置，把「开机时打开」设成你常用的那个 App 或 HDMI 信号源，以后开机不用再翻
3. 扫电视上的二维码，在手机上把不用的系统 App 隐藏掉，顺手排个序
4. 屏保换成航拍，停在主屏幕 10 秒就会开始播，按任意键停在当前画面

## 会踩到的坑

**海信 / Vidda 的工厂菜单**：要进「专业音响设置 → 声音平衡」交替按确认和菜单，左上角出 M 后进工厂菜单，把 To Fac 从 U 改成 M。文档明确写了风险：反复改可能让 USB 失灵、要重置电视。只改一次，别顺手动别的选项。

**只有无线调试的电视要先配对**：Android 11 以上的部分机型（比如索尼 BRAVIA 的 Android 14）不提供 5555 明文端口，直接 adb connect 连不上。要在电视上打开「无线调试 → 使用配对码配对设备」，用屏幕上的 IP:端口和 6 位配对码先 adb pair。

**部分 TCL 固件没有配对码入口**：Q10M、Q10L、鹤 6 Ultra 这些机型找不到配对码入口，只能用数据线先连一次电脑授权，再 adb tcpip 5555。

**没电脑怎么办**：文档里提到有用户用手机上的甲壳虫 ADB 助手、超级小爱装成功过，但作者写了「没有逐一实测」。想稳一点还是用电脑。

**装完不是终点**：不设默认桌面的话，电视重启可能又回到厂商桌面。验收标准是主页键之后的 mCurrentFocus，设好之后才算完。

## 适合

- 家里电视开机有广告、首页推一堆你不看的内容
- 常用的就那三五个 App，受够了每次开机翻半天
- 愿意花 20 分钟折腾一次，之后几年都清净

## 不适合

- 运营商定制机（ADB 通常被锁死，进不去）
- 电视主要用来看厂商自带的内容聚合页
- 一点风险都不想担 —— 海信那一步确实有代价

**说句实话**：它做的是减法：不给你加功能，把首页还给你。风险全集中在「装」的那 20 分钟里，装完就没事了 —— 这也是为什么值得让 AI 陪着装，而不是自己照着六行表格硬啃。
