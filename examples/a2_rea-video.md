# AI 视频越来越逼真，有人做了个工具逐个镜头查它：免费开源，视频不上传，在你自己电脑上跑
*GitHub 开源观察 · 第 01 期 · 单篇 ②/4*

> 看一条爆款短视频，最想知道的是它到底怎么拍出来的。这个工具逐个镜头告诉你，还顺手给一份复刻方案。

rea-video 的功能一句话：把一个视频拆到镜头级，判断每个镜头是实拍、AI 生成、还是代码做的，然后告诉你重做一遍要准备什么。

它的形态有点特别 —— 不是一个你双击打开的软件，而是给 AI Agent 用的一套技能加命令行工具。官方的快速开始就一句话：在 Claude Code、Codex 或任何能跑命令的 Agent 里说「装这个仓库，然后拆解这个视频」，Agent 自己去装 CLI、学流程、跑完。

输出两份东西。一份 report.html（也能导出 PDF）给人看：每个镜头的帧、判断依据、反推出来的提示词、机位和布光说明、音频拆解。另一份 VIDEO.md 给 AI 读：这是作者定义的开放格式，把一次拆解分层放——几百 token 的卡片、一行一镜头的时间线、每个镜头单独一个文件。为什么要分层？一份完整拆解能到几十万 token，不分层，AI 每问一句都得重读一遍。

README 里放的第一个对比很直观：一条 TikTok 广告和它的 AI 翻拍。它的判断是——左边那条全是实拍，一个景、两个机位；右边那条全是 AI，8 个镜头出自 3 次生成。

能拆的类型不少：口播、桌面产品演示、探店 vlog 这类实拍；文生视频、AI 短剧、AI MV；数字人；Blender/C4D 解释动画；动态字体、UI 演示、图表、卡片这类代码动效；软件录屏；以及混剪。混合素材会逐镜头分开判，再按原时间线拼回去。

Apache-2.0，Python 写的，7,000 多 star。它拆的是「怎么做的」，不是「好不好看」—— 这个区别决定了你拿它当工具还是当评审。

## 它替你省掉哪件烦事

想复刻一条视频，最耗时的不是拍，是看出来它怎么做的。一个 30 秒的片子，你得一帧一帧暂停、猜这个转场是拍的还是生成的、猜这个 UI 是模板还是写了代码。

以前这一步全靠经验，而且经验没法复盘 —— 你猜错了自己也不知道。现在它把判断过程摊开成逐镜头的证据：为什么判成 AI、依据是哪几帧、如果重来该给什么提示词。

## 装之前，先确认三件事

- **系统**：Python 3.10 以上（作者建议 3.10–3.14，太新的版本有依赖装不上）+ ffmpeg。Windows 用户注意：安装脚本是 bash，要在 WSL 或 Git Bash 里跑
- **前置**：一个能执行命令的 Agent：Claude Code、Codex，或者桌面版 AI 工具
- **可选**：接一个能看视频的模型（Gemini 或豆包都行），判断更准，还能给每个镜头反推提示词。不接也能跑、完全离线免费——作者给了数字：自己拍的原始文件，不接模型准到 98% 以上；平台下载的重压缩视频掉到 88.6%，接了回到 99.6%
- **输出语言**：报告用你提问的语言写。想要中文就在提示词里明确说「用中文写报告」

## 怎么装：让 AI 替你跑这一步

这个项目本身就是为 Agent 设计的 —— 它没有图形界面，安装、学习流程、执行全靠 Agent。所以在这里，「让 AI 装」不是省事的小技巧，是它设计的唯一用法。

官方的安装路径有两步是 AI 特别擅长的：判断你的环境缺什么（Python 版本、有没有 ffmpeg、pip 能不能用），以及装完之后自己跑一遍验证。这两步人做要翻文档，AI 做是顺手。

提醒一句：它要 clone 仓库、装 CLI、往 ~/.claude 或 ~/.codex 里链技能。装之前先让 AI 说清楚它打算把东西放到哪，别装完找不到。

```text
请帮我在本机装好 rea-video（https://github.com/JuneYaooo/rea-video），然后用它拆解一个视频。

我的系统：<Windows / macOS / Linux，具体版本你查>
要拆的视频：<本地文件路径，先用 15 秒左右的短片试>

要求：
1. 先读 README 和安装文档，确认我要装的东西会落在哪些目录，装在之前先告诉我。
2. 一次一步：先查环境（Python 版本、ffmpeg、pip/pipx 能不能用），有问题先修，再往下。
3. 缺依赖优先用虚拟环境或独立目录，不要动我全局的 Python 环境。
4. 命令你自己执行，报错把原始输出贴给我，先解释再修。
5. 拆解报告用中文写。
6. 我没有视频模型的 key，先用纯本地模式跑；跑完告诉我哪些镜头建议再核一遍。

装完先跑 --help 贴给我看，再拿那个短片跑一次完整拆解，最后告诉我 report.html 在哪、以及哪些镜头的判断是「不确定」。
```

它如果说「不接视频模型也能跑」——对，自己拍的原始文件上确实够准；但你拆的多半是平台下载的重压缩视频，让它在报告里标出哪些镜头没经视频模型核过，这些结论打个折。

想更准：给它一个 Gemini 或豆包的视频接口和 key，让它对不确定的镜头再判一次，对比两次结论。

**用之前先知道**

- 它会把技能链到 ~/.claude、~/.codex 或 ~/.agents，装之前问清楚落在哪
- 先拿 15 秒的短片跑通流程，别一上来丢一个十分钟的视频
- 拆解是学结构和拍法用的——README 明确写了：别搬运别人的画面、音乐和形象，发布时守平台的 AI 标注要求

## 不想用 AI？手动三步

```bash
brew install ffmpeg            # Ubuntu 用 sudo apt install ffmpeg
git clone https://github.com/JuneYaooo/rea-video && cd rea-video
bash scripts/install_skill.sh  # 装 CLI，并把技能链到 ~/.claude 等目录
rea-video --help

# 用法：在 Agent 里说一句话就行
拆解这个视频：/path/to/video.mp4
```

install_skill.sh 会用 pip 装 CLI；系统 Python 不让直接装（PEP 668）就退到 pipx，再不行装进仓库里的 .venv 并把命令链到 ~/.local/bin。想手动挂视频模型，把 endpoint 和 key 给 Agent，它会写进配置。另外 docs/ 目录里的文档（检测规则、怎么复刻、CLI 用法）目前都是中文写的，翻起来不费劲。

## 第一次打开，先做这三件事

1. 先跑一个你自己拍的短片，看它的判断和你记忆里对不对 —— 这是校准「它准不准」最快的办法
2. 打开 report.html，专门看标了「不确定」的那几个镜头
3. 如果接了视频模型，把同一个视频再跑一遍，对比两次的结论差在哪

## 会踩到的坑

**它是给 Agent 用的，不是给人用的**：没有图形界面。你要是打算「下载下来双击用」，这个项目不适合你 —— 它需要 Claude Code、Codex 或桌面版 AI 这类能执行命令的环境。

**不接模型时，平台下载的视频会掉准头**：作者公布了数字：自己拍的原始文件，纯本地跑 98%–99% 准；但从抖音、微信保存下来的视频被平台重新压缩过，噪点证据被抹掉，掉到 88.6%，接个 Gemini 或豆包回到 99.6%。你要拆的多半就是平台下载的视频，所以这一步建议接。

**安装位置不透明**：install_skill.sh 会往 ~/.claude、~/.codex、~/.agents 里链技能。装完找不到东西是常事，装之前就让 AI 说清楚。

**报告语言跟提问走**：默认可能给英文。要中文就在提示词里写死「用中文写报告」，别等出来了再翻。

## 适合

- 做短视频/广告，想拆竞品是怎么做的
- 自己用 AI 生成视频，想知道别人的提示词大概怎么写
- 已经在用 Claude Code 或 Codex，想要一个能直接干活的技能

## 不适合

- 没有 Agent 环境，只想装个软件点点用
- 想让它评判片子好不好看（它只判怎么做的）
- 期待全自动复刻 —— 装了配套的 capsule-cinema 后，AI 镜头能自动生成并放回原时间线，但实拍镜头还得你自己拍，代码镜头它写成 Remotion 工程交给你

**说句实话**：这个项目的门槛不在装，在「你得先有一个能跑命令的 Agent」。有这个前提，它是这期最锋利的一个；没有，它就是一堆读不懂的 Python。
