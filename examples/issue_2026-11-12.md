## 1. Aerial：给国产电视换一块没有广告的桌面
> 把小米、TCL、创维、海信上的开机广告和推荐流一次性清掉，换成一个照着 Apple TV 做的桌面：只有你的 App、壁纸和航拍屏保。

![pengchujin/aerial-tv](https://opengraph.githubassets.com/1/pengchujin/aerial-tv)

**为什么是它**：10 月 20 日建库，22 天涨到 1.1 万 star。它不是又一个「去广告脚本」，而是一套完整的电视桌面 —— 作者连 114 段 Apple TV 航拍影片、用手机扫码整理图标的配套网页都做完了，属于一个人干了半个团队的活。中文圈目前还没有人认真写过它。

国产电视烦人的地方从来不是硬件，是那块开机 15 秒的广告位、关不掉的推荐流、藏在「应用中心」里的系统 App。装 Aerial 之后，盒子还是原来那个盒子，只是开机直接进你的桌面：常用 App 排在下方玻璃底板上，往下是全部应用，连米家这类被藏起来的也能翻出来。电视支持的话，屏保能播 4K 杜比视界的航拍。

**三步用起来**
1. 电脑和电视连同一个 Wi-Fi，按 README 的分品牌说明打开电视的 ADB 调试（小米在「账号与安全」，TCL 在「关于-本机信息」里快速按上下左右，海信要进工厂菜单）
2. 在电脑上跑仓库里的 install.sh，脚本通过 adb 装好并设成默认桌面 —— 不 root、不卸载任何系统应用，随时能还原
3. 重启电视，确认开机直接进 Aerial；想还原就按 README 里那条命令跑回去

**说句实话**：门槛在第二步：海信那种要进工厂菜单改 To Fac 的机型，按错可能让 USB 失灵、得重置电视 —— 作者在文档里写了警告，但不少人看到这段就会放弃。所以它更适合愿意照着文档一步步来的人。

https://github.com/pengchujin/aerial-tv（11294 star · Kotlin）

## 2. rea-video：把一条视频拆到每个镜头，告诉你它是怎么做的
丢一条视频进去，它逐镜头判断这是实拍、AI 生成还是代码画出来的，再给出复刻思路。

**点评**：本质是个跑在 Claude Code / Codex 里的工作流，不是双击就能用的软件；「是拍的还是 AI 生成的」这一判断目前还需要人来复核。

https://github.com/JuneYaooo/rea-video（7086 star · Python）

## 3. pixelfx：244 个像素特效，每一个都是一小段能改的代码
篝火、爆炸、瀑布、传送门、龙卷风……244 个像素风特效，能在线玩、能改色镜像、能导出成 sprite sheet 塞进任何引擎。

**点评**：真能直接用的是其中三十来个；但附带的那个 Claude Code 技能更值钱 —— 它让 AI 像挑剔的像素画师那样画、看、改，而不是一次生成一堆废图。

https://github.com/patch-gg/pixelfx（7000 star · JavaScript）

## 4. 中小学知识图谱：1644 个知识点，2403 条先修关系
数学、英语、物理、语文、化学、生物的知识图谱，对齐 2022 版课标和现行人教版教材，还带 6723 道配套题。

**点评**：它最聪明的设计是答错之后沿先修边往回追：高中题错了，一路定位到你小学哪个知识点没打牢。注意许可是 CC BY-NC —— 自己用、给孩子用都行，别拿去做付费课。

https://github.com/xiaoyang111222/cn-math-taxonomy（7694 star · Python）
